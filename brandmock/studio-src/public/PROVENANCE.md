# Release 0.6 — separate Studio T-shirt

tee-studio is derived from the user-supplied BrockCreative tee. It changes the fit (width ×1.14, height ×0.94, depth ×1.04), reshapes the crew neck, welds coincident seam vertices, gently smooths interior cloth vertices, and assigns a rib-knit collar. The existing tee-regular assets remain unchanged. The original second UV set is retained for the author’s sewing and fabric normal atlas. The new print metadata records the deliberate fit scale; user artwork keeps its own physical aspect ratio.

textures/tee-studio/original-normal.png is the unmodified FBX_normal.png supplied with the BrockCreative T-shirt. It inherits the source asset’s terms, not the ambientCG CC0 license. Hash and origin are recorded in textures/tee-studio/PROVENANCE.json. No model or texture from brandmockups.store is included.

# BrandMock Studio 0.4 — asset provenance

The regular and oversized T-shirts are original prepared quad meshes generated by tools/build_garments.py. Blender sources are in sources/. Their cloth geometry, collars, seam curves and cut-pattern UVs were authored for BrandMock.

The current hoodie is an adaptation of **Hoodie by ShoyoX**, licensed **CC BY 4.0**:
https://sketchfab.com/3d-models/hoodie-2c674228f1e946b5b8f508f8f818e130 .
The prepared source mesh was publicly redistributed by omikhan4901/teestudio at commit 95c67447a81196b006fbdab8e0cca2f5dd87b312. That distribution credited yogaminggames; the current original-model API credits ShoyoX. The original model ID is identical. The original source file, URLs, hash and attribution history are recorded in sources/vendor/PROVENANCE.json. It contains no rig, human skin or avatar.

BrandMock adaptations: relaxed distal sleeve pose with fixed shoulder boundaries; orthogonal orientation and uniform physical scale of the original sewing-pattern UVs; four independent print materials; front-pocket print registration; sleeve placement calibration; application metadata. The artist's UV distances are retained without anisotropic rescaling, verified by tests. The interface links the original author and license. Copyright/credit is also embedded in the exported GLB. See licenses/HOODIE-CC-BY-4.0.txt.

Runtime fine fabric maps derive from **ambientCG Fabric034**, **CC0 1.0 Universal**: https://ambientcg.com/a/Fabric034 . Normal and roughness maps are resized to 512px; the color map is converted to neutral grayscale detail. See textures/PROVENANCE.json and licenses/CC0-1.0.txt. Rib-knit normals are original procedural maps. Maps are self-hosted; no runtime requests go to these external services.

No commercial files, models, photographs or logos from the reference store are included. The reference video was used to assess form, cloth appearance and workflow. No generative image or logo API was used. User logos are retained byte for byte in projects; the sample FORME logo is original demo artwork.

The environment uses Three.js RoomEnvironment; the ground shadow is an application approximation. Dependencies retain their respective licences in licenses/. Source and browser model hashes are listed in models/manifest.json.
