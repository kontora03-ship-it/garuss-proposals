# Studio 0.8.3 surface-print validation

The supplied screenshot showed severe stroke stretching and missing lettering. The failure was reproduced on the 0.8.2 planar back mapping near a 60-degree rear view. Width/height projection tests and straight upper-back renders had missed it: a flat map reverses signed UV orientation where the actual cloth folds back in that projection. This release replaces the flat back map and the legacy front map with continuous angle-based unwraps of the actual cloth surface.

Every actual UV triangle has a consistent signed area. The intrinsic Jacobian uses a basis on each 3D triangle, not a projection onto camera width/height. Measured local scale is 0.8707–1.1574 on the front and 0.7997–1.2455 on the back; maximum anisotropy is 1.2117 and 1.0802 respectively. All 62,089 front and 65,562 back triangles are checked. Reconstructing the old flat projection on the same folded geometry exposes its reversed triangles. The earlier flat tests could report success while the actual UVs folded over, so they are not used as the final regression criterion.

The deep central back groove is also relaxed toward a smooth quadratic depth field, with an 85% local blend, a 0.09 additional-depth cap, smooth width/height fades and fixed material boundaries. Width and height remain fixed. Direct exported-buffer comparison verifies the front, collar, sleeve and hem positions and original fabric-atlas UV1 are retained; only back depth changes. Normals follow the actual adjusted surface. Customer logo files and project settings remain intact. Default demo physical anchors are retained; other placements may move slightly with the new unwrap. Actual folds may naturally hide part of artwork at oblique angles, but must not smear strokes along the surface.

Build: npm run build. Geometry: npm test. Browser: extract tee-studio.glb and its JSON from baseline commit 117c581dd57879d84b1381a5c98aa70f52a85b61, start Vite preview on 5182, then STUDIO_BASELINE_GLB=<path> STUDIO_BASELINE_JSON=<path> BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:torso-print. Default test baseline is frozen Studio 0.6.

Browser cases export BrandMock on the lower torso, capture both sides rotated around 60 degrees, show a rectangular SVG at three heights on each side, drag it on the lower torso and verify saved-project reload. Calibration screen-space variations are recorded as natural cloth drape, rather than forcing straight 2D baselines. Evidence PNGs live under ignored test-artifacts/torso-print/. Public comparisons only crop/resize actual renders and add labels.

The collar opening and band dimensions are retained. A few outer-band samples conform to the adjusted support surface within 0.000101 scene units per axis; this is recorded in checks.json.
