# BrandMock LAB 0.6

Отдельная экспериментальная версия. Стабильные `brandmock/app` и `brandmock/online` не меняются.

- LAB: https://kontora03-ship-it.github.io/garuss-proposals/brandmock/next/
- Стабильная: https://kontora03-ship-it.github.io/garuss-proposals/brandmock/app/

## Использование

1. Загрузите JPG/PNG/WebP изделия и оригинал логотипа (включая безопасный SVG и JPG). Выберите тип изделия.
2. Нажмите «Найти изделие ИИ». Для кружек YOLOS ищет класс cup, SlimSAM выделяет маску. Для ткани SlimSAM получает точку в центре фотографии; тип ткани выбирает пользователь. Если предложена неправильная маска, выберите «Указать изделие одним кликом» и кликните по нужному предмету.
3. Проверьте область. Передвигайте четыре угла и крестик логотипа, меняйте масштаб и поворот. Для кружки доступны кривизна и изгиб по высоте. Сетка показывает деформацию поверхности. Можно задать четыре угла полностью вручную.
4. Выберите печать, серебро, золото или блинтовое тиснение. Скачайте PNG, изображение до/после или ZIP проекта. ZIP содержит оригиналы и JSON версии 6, в том числе маску и поле ткани.

Первая демонстрация имеет заранее размеченную область, отмеченную как демонстрационная. Для настоящего распознавания нажмите кнопку ИИ. Футболка и полотенце — авторские синтетические тестовые сцены, не доказательство работы на любой фотографии. После загрузки своей фотографии старые маска и область удаляются; до распознавания или ручной разметки видна исходная фотография, экспорт нанесения отключён.

## Обработка и ограничения

Вся обработка выполняется на устройстве. Модели и WASM загружаются с того же сайта; фото не отправляется в API. Платных сервисов нет. Первое использование ИИ требует загрузки примерно 45–60 МБ ресурсов и может занять минуту и более на слабом устройстве. ИИ работает в отдельном Worker; кнопку отмены можно использовать во время распознавания. Для моделей требуется современный браузер с WASM SIMD. Фото анализируется в размере до 640 px по длинной стороне; экспорт выполняется в исходном разрешении (до 12 Мп).

Маска — семантическое выделение объекта, а не измеренная 3D-модель. Для кружки алгоритм предлагает центральную область корпуса по сечениям маски и цилиндрическую модель с регулируемыми параметрами. Длинная ручка, конусный или сильно наклонённый корпус, несколько предметов, прозрачное стекло, перекрытия и сложный фон могут потребовать одного клика или ручной разметки. Кривизна и глубина не могут однозначно восстановиться по одной фотографии. Пропорции исходного логотипа сохраняются в параметрических координатах поверхности; точность её оценки требует визуальной проверки.

Для маек и полотенец определяются маска и консервативная область нанесения. Слабая деформация рассчитывается по сглаженной светотени, с ограничением производной для предотвращения самопересечения. Это приближение: рисунок ткани и тень могут ошибочно восприниматься как складки. Настоящая геометрия глубоких складок, скрытых участков и пересечений не восстанавливается. Уменьшите «Учёт складок» при ошибке. Не используется генеративная перерисовка фото или логотипа.

Пиксели вне альфы нанесения сохраняются без изменений. Маска объекта дополнительно обрезает нанесение. Исходные файлы в ZIP сохраняются как были загружены. JPG преобразуется в редактируемую растровую маску с удалением однотонного фона и перекраской; это не векторизация.

## Windows / локальный запуск

Установите Node.js 22 LTS или новее. В PowerShell откройте `brandmock/next-src`:

```powershell
npm ci --ignore-scripts
npm run dev -- --port 5176
```

Откройте http://localhost:5176. Флаг `--ignore-scripts` исключает ненужную браузеру установку CUDA для зависимости Node ONNX. Модели и WASM уже включены в `public`; дополнительные аккаунты и ключи не требуются.

Сборка и просмотр готовой версии:

```powershell
npm run build
npm exec vite preview -- --port 5177
```

Публиковать содержимое `dist` в отдельный каталог `brandmock/next`. Корректны относительные пути, включая Worker и модели. Источники размещены в `brandmock/next-src`. IndexedDB `brandmock-lab-v1` и ключ `brandmock-lab-last` изолированы от стабильной версии. LAB импортирует старые ZIP версии 1–5; ZIP LAB версии 6 нужно открывать в LAB. Старые сохранённые проекты автоматически не изменяются.

## Проверки

```powershell
npm test
npm run test:ai
npm exec playwright install chromium
$env:BRANDMOCK_TEST_URL="http://localhost:5177"
npm run test:e2e
```

`npm test`: прежние проверки перспективы, альфы, неизменности оригинала и повторяемости, плюс реальная цилиндрическая деформация, прямое/обратное отображение, обрезка маской, слабая деформация ткани, тонкие линии и мелкие штрихи. `test:ai`: реальный CPU inference без сетевого API. `test:e2e`: Chromium, настоящие браузерные модели, три демо, четыре эффекта, исходное разрешение PNG и повторное открытие ZIP с маской, изоляция localStorage, отсутствие внешних сетевых запросов. Результаты и PNG пишутся в `test-artifacts`.

Модули: `aiCore`/`ai.worker` — модели, `objectGeometry` — выбор области, `objectMask` — маска, `curvedSurface` — модели поверхности, `curvedWarp` — OpenCV remap, `placementGeometry` — координаты логотипа, `SurfaceEditor` — интерактивное редактирование, `online` — локальные файлы, эффекты, экспорт и IndexedDB. Алгоритмы не смешиваются с компонентами React.
