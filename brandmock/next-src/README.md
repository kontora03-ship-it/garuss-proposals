# BrandMock LAB 0.7

Отдельная браузерная версия: https://kontora03-ship-it.github.io/garuss-proposals/brandmock/next/

Стабильные `brandmock/app` и `brandmock/online` остаются без изменений. LAB хранит проекты в отдельной IndexedDB `brandmock-lab-v1`.

## Что изменено в 0.7

- Основной поиск теперь использует быстрый анализ контура, без скачивания и запуска нейросетей. При замене фотографии он выполняется автоматически. Можно повторить кнопкой «Быстрый поиск».
- Сложный фон не вызывает автоматический запуск тяжёлого ИИ: приложение предлагает один клик по изделию или ручные четыре угла. Режим «Уточнить с ИИ по точке» использует SlimSAM без предварительного YOLOS. Он по-прежнему требует загрузки модели и времени на вычисления; это отдельное действие пользователя.
- Кэш декодированных исходников, отдельный рабочий предпросмотр до 1200 px, экспорт в полном исходном разрешении. Масштаб предпросмотра не меняет сохранённые координаты и оригиналы.
- Футболки/майки, худи/свитшоты, поло/рубашки. Область следует оси торса, определяется по боковым границам корпуса с отступами от рукавов и горловины, проверяется по маске. Для худи предусмотрен отступ от капюшона и кармана, для поло — от воротника/планки.
- Зоны: центр груди, левая грудь изделия, спина. Для спины загрузите фотографию сзади. После смены зоны повторите быстрый поиск.
- Полотенца удалены из меню, демонстраций и новых режимов анализа. Старые ZIP ткани можно открыть и отредактировать вручную; исходники и маска не удаляются.

На тестовом Chromium быстрый анализ контура и подбор области заняли 0,1–0,2 с для синтетических каталожных примеров. Это не обещание скорости и точности на любом фото. Замеры, реальные PNG и скриншоты — в `validation/v0.7/`.

## Как работать

1. Выберите тип изделия, загрузите JPG/PNG/WebP (до 20 МБ и 12 Мп), затем SVG/PNG/WebP/JPG логотипа. Исходные файлы сохраняются без изменений. Поиск простого контура запускается автоматически при загрузке фотографии.
2. Проверьте рамку. Если фон неоднородный или изделие не выделилось, нажмите «Уточнить с ИИ по точке» и кликните по ткани на груди или по корпусу кружки. Можно отменить поиск. Альтернатива — четыре угла вручную.
3. Передвигайте логотип крестиком, поправляйте углы, масштаб, поворот. Сетка показывает искривление. Выберите зону одежды и повторите быстрый поиск для её пересчёта. Для кружки регулируются кривизна и изгиб по высоте.
4. Выберите печать, серебро, золото или блинт. Экспорт PNG всегда в исходном разрешении; «до/после» — двойная ширина. ZIP версии 6 содержит оригиналы и JSON, включая маску, профиль одежды и настройки поверхности. LAB импортирует ZIP 1–6; новые ZIP открывайте в LAB.

Демо с футболкой, худи и поло — авторские синтетические стенды на простом фоне. Их начальные рамки заданы заранее и явно отмечены как демонстрационные. Кнопка поиска действительно анализирует изображение. Реальные фото футболки на человеке и худи со спины используются в тестах режима ИИ по точке, а не как доказательство универсального быстрого распознавания.

## Ограничения

Быстрый алгоритм рассчитан на отдельное изделие на относительно однородном фоне. Он сравнивает цвета с фоном и выделяет связный контур; это не семантический классификатор одежды. На сложном фоне, белом изделии на белом фоне, обрезанном предмете или человеке целиком нужна проверка, ИИ по точке либо ручная разметка. Автоматического восстановления скрытой ткани и разделения всех предметов одежды нет.

SlimSAM также выдаёт маску, а не измеренную 3D-поверхность. Первая загрузка режима по точке — примерно 35 МБ весов и WASM плюс библиотека; на слабом устройстве обработка может занимать десятки секунд. При повторном клике по тому же фото модель повторно использует признаки изображения. Подключений к платным API и отправки фото на сервер нет. Модели и runtime загружаются с того же сайта. Нужен современный браузер с WASM SIMD.

Складки учитываются ограниченной деформацией по сглаженной светотени. Рисунок ткани может ошибочно влиять на поле; глубокие складки, руки поверх груди, капюшон, застёжки и перекрытия требуют ручной проверки. Параметр «Учёт складок» можно уменьшить. Это визуальное приближение, а не физическая модель или точное восстановление глубины.

Логотип сохраняет исходные пропорции в координатах выбранной поверхности. Пиксели исходной фотографии вне альфы нанесения не изменяются. JPG-логотип редактируется как растровая маска с удалением однотонного фона и сменой цвета; это не автоматическая векторизация. Генеративной перерисовки исходников нет.

## Запуск на Windows

Node.js 22 LTS или новее. PowerShell в папке `brandmock/next-src`:

```powershell
npm ci --ignore-scripts
npm run dev -- --port 5176
```

Открыть http://localhost:5176. Флаг исключает ненужную браузеру установку CUDA для Node-зависимости ONNX.

```powershell
npm run build
npm exec vite preview -- --port 5177
```

Открыть http://localhost:5177. Публиковать только содержимое `dist` в `brandmock/next`. Не заменять стабильные папки.

## Тесты

```powershell
npm test
npm run test:ai
npm run test:clothing
npm exec playwright install chromium
$env:BRANDMOCK_TEST_URL="http://localhost:5177"
npm run test:e2e
npm run test:point
```

`test`: перспектива, альфа, пропорции, неизменность исходника, повторяемость, цилиндр, ткань, тонкие штрихи; быстрый контур, наклон одежды, зоны и отказ на пустом фото. `test:ai`: прежнее настоящее CPU-распознавание кружки. `test:clothing`: SlimSAM на реальных футболке и худи. `test:e2e`: быстрый браузерный режим без запросов моделей, три профиля, ZIP, четыре эффекта, раздельное разрешение preview/export и замеры. `test:point`: настоящий браузерный ИИ по клику на реальной футболке, без загрузки YOLOS. Результаты — в `test-artifacts`.

Модули: `fastSurface` — быстрый контур, `aiCore`/`ai.worker` — модели, `garmentGeometry` — ось торса и зоны, `objectGeometry` — область нанесения, `curvedSurface`/`curvedWarp` — деформация и OpenCV, `SurfaceEditor` — управление, `online` — локальное хранение, кэш, эффекты и экспорт.

Источники моделей и лицензии: [public/THIRD_PARTY.md](public/THIRD_PARTY.md). Точные ревизии и SHA-256: `public/models/manifest.json`. Тестовые логотипы собственные; фотографии не содержат используемых без разрешения чужих товарных знаков.
