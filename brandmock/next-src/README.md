# BrandMock LAB 0.8

Браузерный редактор: https://kontora03-ship-it.github.io/garuss-proposals/brandmock/next/?v=0.8

Стабильные `brandmock/app` и `brandmock/online` не меняются. Исходники LAB — `brandmock/next-src`, сборка — `brandmock/next`. Проекты LAB хранятся отдельно в IndexedDB `brandmock-lab-v1`.

## Работа

1. В библиотеке выберите тип изделия и фасон/форму. В комплекте 10 настоящих фотографий: две футболки, худи и свитшот, две кружки, две картонные упаковки и две кепки. Выбор меняет фото и подготовленную поверхность, сохраняя ваш логотип и настройки нанесения. Загрузка моделей для библиотеки не требуется.
2. Выберите цвет изделия из палитры или свой цвет. Это программная визуализация по маске, сохраняющая фактуру и светотень. «↺» возвращает оригинал. У тракера перекрашивается передняя панель; сетка и козырёк сохраняются.
3. Свой JPG/PNG/WebP по-прежнему можно загрузить сверху. Это снимает библиотечную маску и цвет. Выбор типа на своём фото запускает соответствующий поиск поверхности. Для своей кепки укажите четыре угла панели вручную; у библиотечных кепок разметка уже есть.
4. Загрузите SVG/PNG/WebP/JPG логотипа. Блок «Цвет логотипа» под загрузкой содержит палитру и HEX. В печати включается монохромная перекраска с сохранением альфы и просветов. В золоте/серебре меняется цвет покрытия; у блинта краски нет. Для JPG доступно удаление однотонного фона; это растровая маска, не векторизация.
5. Двигайте логотип крестиком и корректируйте углы, масштаб и поворот. Все числовые настройки имеют кнопки −/+ и ввод числа: поворот 1°, размер/положение/прозрачность/интенсивность 1%, свет 1°, углы 1 px, пропорции поверхности 0,01. Масштаб холста можно вводить отдельно. На кнопках есть подсказки.
6. Сохраните проект в браузере или скачайте ZIP для переноса. PNG экспортируется в исходном разрешении, «до/после» — в двойной ширине. ZIP содержит оригинальные фото и логотип, JSON версии 6 с геометрией, масками и цветами, а для библиотеки — SOURCE-CREDIT.txt. Импортируются ZIP версий 1–6; новые проекты открывайте в LAB.

Источники фотографий и лицензии видны у каждого изделия. Полный список — `public/catalog/CREDITS.md`, точные размеры файлов и SHA-256 — `public/catalog/manifest.json`. Генеративные изображения в библиотеке не используются. Исходные JPEG сохраняются как были скачаны; изменения цвета и логотипа воспроизводимы из JSON. Фотографии CC BY-SA и их изменённые изображения сохраняют соответствующую лицензию; код приложения лицензируется отдельно.

## Свои фотографии и ограничения

Быстрый анализ контура рассчитан на отдельный предмет на относительно однородном фоне. При загрузке своего фото он запускается автоматически для поддерживаемого типа. Это анализ фона/цвета, а не семантический классификатор всех видов одежды. При неуверенном результате приложение оставляет исходник и предлагает ручные углы или ИИ по точке.

«Уточнить с ИИ по точке» работает локально через SlimSAM. После кнопки редактор прокручивается к фото; кликните по ткани или корпусу кружки. Текущий этап и отмена видны также на холсте. Первая загрузка режима по точке — около 35 МБ модели и WASM плюс библиотека. В проверке на реальной футболке браузерная обработка заняла 14–17 секунд; на другом устройстве и при загрузке по интернету будет иначе. Повторные точки используют сохранённые признаки того же фото. Фото не отправляется в API.

Маска не является измеренной 3D-моделью. Для кружки используется цилиндрическая проекция с регулируемой кривизной. Складки одежды учитываются ограниченной деформацией по светотени: рисунок ткани, глубокие складки и перекрытия требуют проверки. Автоматического восстановления скрытой ткани нет. Логотип сохраняет пропорции в координатах выбранной поверхности; точность её оценки проверяет пользователь.

Пиксели вне альфы нанесения не меняются; при явно выбранном цвете библиотечного изделия меняются также пиксели внутри отдельной маски окрашивания. Фон вне обеих масок остаётся исходным. Редактируемый предпросмотр ограничен 1200 px, экспорт остаётся в исходном размере (до 12 Мп). Максимальный файл — 20 МБ. Нужен современный браузер; для ИИ — WASM SIMD. Платных API, аккаунтов и серверной обработки нет.

## Windows / локальный запуск

Установите Node.js 22 LTS или новее. В PowerShell откройте `brandmock/next-src`:

```powershell
npm ci --ignore-scripts
npm run dev -- --port 5176
```

Откройте http://localhost:5176. Флаг исключает ненужную браузеру установку CUDA для Node-зависимости ONNX.

```powershell
npm run build
npm exec vite preview -- --port 5177
```

Откройте http://localhost:5177. Для GitHub Pages копируйте содержимое `dist` только в `brandmock/next`.

## Проверки

```powershell
npm test
npm run test:ai
npm run test:clothing
npm exec playwright install chromium
$env:BRANDMOCK_TEST_URL="http://localhost:5177"
npm run test:e2e
npm run test:point
```

- `test`: перспектива, альфа, пропорции, исходные пиксели, повторяемость, цилиндр/ткань, тонкие штрихи; быстрые контуры и зоны одежды; детерминированная обратимая перекраска изделия только внутри маски.
- `test:ai` и `test:clothing`: реальные CPU-модели на кружке, футболке и худи.
- `test:e2e`: 10 фото, выбор категорий/фасонов/цветов, сохранение логотипа, шаговые кнопки, подсказки, цвета логотипа, исходный размер PNG, неизменность фона, ZIP и возврат к своему фото.
- `test:point`: настоящий браузерный ИИ по клику на реальной футболке.

Артефакты — в `test-artifacts`; сохранённые отчёты — в `validation`. Синтетические стенды предыдущих версий остаются только как тестовые исходники, основной каталог использует фотографии. Полотенец в текущем интерфейсе нет.

Модули: `ProductLibrary`/`catalog` — выбор фото, `productColor` — маска окрашивания, `NumberControl` — точное управление, `LogoColor` — цвет логотипа, `fastSurface`/`aiCore` — анализ, `garmentGeometry`/`objectGeometry` — область, `curvedSurface`/`curvedWarp` — деформация/OpenCV, `SurfaceEditor` — холст, `online` — локальные файлы, кэш, эффекты, ZIP и PNG.

`test/prepare-catalog.mjs` и `test/refine-catalog.mjs` — офлайн-инструменты подготовки масок по фотографиям в `public/catalog`. Они не запускаются приложением. После повторной подготовки требуется визуальная проверка; проверенные маски уже входят в комплект. Модели и лицензии: `public/THIRD_PARTY.md`, `public/models/manifest.json`.
