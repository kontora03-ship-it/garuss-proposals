## Онлайн-приложение

Открыть BrandMock: https://kontora03-ship-it.github.io/garuss-proposals/brandmock/app/

Онлайн-версия обрабатывает изображения через OpenCV.js в браузере, сохраняет проекты в IndexedDB и экспортирует переносимый ZIP. Установка Python не нужна. В версии 0.2 добавлены удаление однотонного фона JPG, выбор цвета логотипа, скачивание отдельного прозрачного PNG, предложение поверхности по контурам и перемещение логотипа мышью. Исходники онлайн-версии находятся в `online/`, сборка для GitHub Pages — в `app/`. Локальная Python-версия и инструкция ниже сохранены.

# BrandMock — MVP 0.1

Локальный редактор нанесения оригинальных логотипов на плоские поверхности. React + TypeScript + Vite + react-konva; FastAPI + OpenCV + Pillow + CairoSVG. Нет регистрации, базы данных, платных API и генеративной обработки.

## Запуск на Windows 10/11

1. Установите Python **3.12 x64** и Node.js **22 LTS**. При установке Python включите Add to PATH.
2. Распакуйте проект в доступную для записи папку. Запустите `start-windows.bat`.
3. Откройте **http://127.0.0.1:8000**. Держите окно сервера открытым.

В поставке есть готовый `frontend/dist`, поэтому Node нужен только для изменения/пересборки интерфейса. Первый запуск скачивает Python-зависимости.

**Cairo на Windows:** CairoSVG требует нативную библиотеку Cairo. Если появляется `no library called cairo-2 was found`, установите MSYS2 x64, выполните в UCRT64 `pacman -S mingw-w64-ucrt-x86_64-cairo`, добавьте `C:\msys64\ucrt64\bin` в PATH и откройте новый терминал. Альтернатива — WSL2 Ubuntu с `sudo apt install libcairo2` и запуском командами ниже. Linux-прототип проверен; Windows-инсталлятор в этом окружении не выполнялся.

Ручной запуск в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
.\.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Linux/macOS (нужна системная Cairo):

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cd frontend && npm ci && npm run build && cd ..
.venv/bin/uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Разработка: backend на 8000, `cd frontend; npm run dev` на 5173 с Vite proxy. API: `/docs`.

## Работа

1. Загрузите фотографию JPG/PNG/WebP и логотип SVG/PNG/WebP/JPG. Новая пара файлов создаёт новый проект; оригинальные байты сохраняются отдельно.
2. Расставьте углы **1 → 2 → 3 → 4**: верхний левый, верхний правый, нижний правый, нижний левый в системе координат поверхности. Начальный угол можно выбрать на повёрнутом изделии; обход должен быть по часовой стрелке. Пересечения и невыпуклые/слишком малые области отклоняются. Можно ввести координаты численно.
3. Укажите ширину/высоту поверхности в одинаковых единицах. Четыре точки сами по себе не определяют физические пропорции плоскости. Логотип вписывается с сохранением собственного соотношения сторон, затем масштабируется/поворачивается/перемещается **в координатах поверхности**, после чего применяется homography.
4. Выберите режим. Полноцветная печать сохраняет цвета; цветовой переключатель доступен для металлов. Свет управляет тиснением. Положение задаётся в процентах поверхности. Изображение вне плоскости обрезается.
5. «Сохранить проект» сохраняет серверный JSON. «Проект ZIP + JSON» скачивает переносимый архив с обоими неизменёнными оригиналами и JSON. «Открыть проект» восстанавливает ZIP. PNG и «До/после» автоматически сохраняют текущие настройки перед экспортом.

Zoom влияет только на редактор; PNG всегда в исходных размерах (с учётом EXIF orientation). Экспорт до/после имеет двойную ширину. RGBA сохраняется; итоговая альфа вычисляется по source-over. Прозрачность фотографии под нанесением естественно меняется, вне покрытия остаётся исходной.

## Модули

- `backend/image_loader.py`: ImageLoader — проверка форматов, EXIF, декодирование.
- `backend/logo_loader.py`: LogoLoader — ограниченный безопасный SVG и растровые логотипы.
- `frontend/src/SurfaceEditor.tsx`: SurfaceEditor — интерактивные точки Konva.
- `backend/geometry_engine.py`: GeometryEngine — плоскость, пропорции, homography, premultiplied warpPerspective.
- `backend/material_effects.py`: MaterialEffects — четыре детерминированных режима.
- `backend/preview_renderer.py`: PreviewRenderer — RGBA-композитинг, точное сохранение пикселей с нулевым покрытием.
- `backend/export_service.py`: ExportService — PNG.
- `backend/storage.py`: ProjectStorage — локальные оригиналы, атомарная запись JSON, переносимый ZIP.
- `backend/quality_validator.py`: QualityValidator — проверка координат/выпуклости/площади.
- `backend/surface_detector.py`: Protocol для будущего детектора; реализации и скрытого AI нет.

## Проверки и примеры

```powershell
.\.venv\Scripts\python -m pytest -q
```

Тесты проверяют пропорции, перспективу, прозрачные отверстия, точное сохранение пикселей вне покрытия во всех режимах, тонкие линии, мелкий текст, RGBA/размеры PNG, повторяемость, оригинальные байты в ZIP, восстановление, отклонение плохих четырёхугольников и опасных SVG.

`demo/generate.py` воспроизводимо создаёт три **искусственные** продуктовые сцены и вымышленный логотип FORME. Это геометрические стенды, не фотографии. `demo/real/` содержит две реальные фотографии Unsplash; ссылки и лицензия в `demo/SOURCES.md`. `demo/results/` содержит PNG для всех режимов и переносимый пример проекта. `demo/render_examples.py` заново создаёт их через тот же движок. Фотографии не генерируются и не перерисовываются.

## Честные ограничения

- Только плоская поверхность. Нет оборачивания вокруг кружки, 3D, сегментации, автоматического поиска плоскости или учёта перекрывающих объектов.
- Тиснение — управляемая визуальная имитация, не физическая симуляция металла/деформации. Световые переходы ограничены силуэтом: исходные пиксели вне альфа-покрытия не меняются. Отражение задаётся аналитической функцией, без случайного шума.
- SVG растрируется максимум до 1600 px по длинной стороне; очень крупные экспорты могут терять детализацию. Текст использует установленные шрифты: для точного воспроизведения **переведите текст в кривые**. Нельзя обещать идентичность шрифтов между разными ОС.
- Безопасное подмножество SVG: запрещены scripts, foreignObject, image, use, style, обработчики событий и внешние ссылки. Сложные SVG с CSS/фильтрами могут отклоняться; экспортируйте такой логотип в прозрачный PNG. XML entities/DTD блокирует defusedxml. Изоляция для недоверенного публичного SaaS потребует отдельного процесса, лимитов CPU/памяти и дополнительного аудита.
- Лимит файла 20 МБ, фотографии 20 Мп. Предпросмотр считает полное разрешение с задержкой 180 мс; большие изображения могут обрабатываться медленно. Supersampling и интерактивный GPU-рендер не реализованы.
- Полноцветное наложение идёт в sRGB с небольшой модуляцией фактуры. Профили ICC/CMYK и печатная цветопроба не поддерживаются.
- Изменённые настройки сохраняются кнопкой или перед экспортом; автосохранения нет. Открытие проектов реализовано переносимым ZIP, отдельный JSON без исходников не импортируется.
- Сервис рассчитан на localhost: нет авторизации, многопользовательской изоляции, очистки проектов и production-hardening. Не публикуйте порт в интернете.

Браузерная проверка (при работающем сервере на 8000):

```sh
cd frontend
npx playwright install chromium
npm run test:e2e
```

Она проверяет перетаскивание точки, загрузку настоящего JPG и SVG, все четыре режима, скачивание PNG и восстановление ZIP; скриншот сохраняется в `output/editor.png`. При нестандартном расположении Chrome задайте `BROWSER_EXECUTABLE`.

В среде разработки архив исходников доступен по `/api/download-source`, если подготовлен `output/BrandMock-MVP-0.1.zip`. Это удобство поставки; для работы редактора архив не требуется.
