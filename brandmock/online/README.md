# BrandMock Online 0.3

Онлайн-версия BrandMock: React/TypeScript/Konva + OpenCV.js 4.11, IndexedDB и JSZip. Нативная Python-версия остаётся рядом в репозитории Garuss.

## Возможности

- JPG/PNG/WebP фото, SVG и растровые логотипы, 4 угла плоскости.
- По умолчанию единый масштаб и поворот без деформации (OpenCV warpAffine). Перспектива плоскости включается отдельно после подтверждения пропорций; оба режима используют premultiplied alpha. Четыре программных эффекта, масштаб/поворот/позиция.
- PNG исходного разрешения, до/после, переносимый ZIP с оригиналами и JSON версии 3 для онлайн-редактора.
- Последний проект восстанавливается после перезагрузки. Сохранение — кнопкой или перед экспортом.
- Фотографии и логотипы **не отправляются на сервер**. Исходные байты в ZIP не изменяются.

## Хранение и ограничения

Проекты хранятся только в IndexedDB этого браузера/профиля/домена. Очистка данных сайта удалит их. Для резервной копии и работы на другом устройстве скачивайте ZIP. Облачной синхронизации нет.

Файлы до 20 МБ, фото до 12 Мп, архив до 25 МБ. Большие изображения могут замедлять интерфейс. Только плоские поверхности; физическая симуляция и семантическое распознавание поверхности отсутствуют; автоподсказка использует контуры. Тиснение — визуальная имитация. SVG поддерживает безопасное подмножество без CSS/scripts/image/use/внешних ресурсов и растрируется до 1600 px. Текст SVG зависит от системных шрифтов — переводите в кривые.

Цвет и декодирование изображений выполняет браузер; ICC/CMYK-цветопроба не поддерживается. Результат браузерного движка может не совпадать побайтно с Python-версией из-за декодирования, шрифтов и границ маски. Детерминизм проверяется внутри одного движка. Прозрачные пиксели исходного PNG с ненулевым скрытым RGB могут нормализоваться Canvas; оригинальный файл в ZIP сохраняется без изменений.

Первый запуск загружает локально размещённый OpenCV.js (~11 МБ); платных API нет. OpenCV — Apache 2.0, JSZip — MIT/GPL; см. THIRD_PARTY.md. Авторские тестовые сцены и источники фотографий перечислены в public/samples/SOURCES.md.

## JPG и редактирование логотипа

Загрузите логотип независимо от фотографии изделия. Откройте «Подготовка JPG / логотипа», включите «Убрать однотонный фон» и выберите цвет фона. Предлагается медианный цвет по краям изображения. Допуск компенсирует JPEG-артефакты, мягкость задаёт переход альфа-канала. По умолчанию удаляются только области, связанные с краем. Переключатель «Удалять также фон внутри букв» включает все совпадающие области — он может удалить и внутренние элементы этого цвета, поэтому проверяйте предпросмотр.

«Один цвет для логотипа» позволяет перекрашивать маску с сохранением прозрачности. «Скачать PNG без фона» экспортирует отдельный логотип исходного размера. Оригинальный JPG сохраняется неизменным. Это редактируемая **растровая маска**, не векторные кривые; сложный фотографический фон и ручная кисть-маска пока не поддерживаются.

Новые ZIP-проекты используют JSON версии 3, включая режим размещения и подтверждение пропорций. Онлайн-редактор открывает версии 1, 2 и 3. В проектах без сохранённого режима включается «Без деформации» и появляется пояснение: для прежнего перспективного вида нужно выбрать перспективу и подтвердить пропорции. Исходники и настройки не теряются, но старый результат может выглядеть иначе до включения перспективы. Локальный Python-редактор версии 0.1 открывает только версию 1 и явно отклоняет более новые архивы. Для него можно скачать прозрачный PNG логотипа отдельно.

## Автоматическая область и ручная правка

При загрузке фотографии запускается OpenCV-поиск выпуклого четырёхугольника по контурам (Canny, morphology, approxPolyDP); кнопку «Найти область автоматически» можно нажать повторно. Результат является подсказкой, а не семантическим распознаванием продукции. На текстурированных сценах, криволинейных изделиях и сложном освещении область может не найтись или оказаться неверной. При отсутствии кандидата интерфейс явно просит разметить поверхность вручную.

**Без деформации (по умолчанию).** Автопоиск предлагает только область и начальное размещение. Размер логотипа вписывается с сохранением исходного соотношения сторон; используется один коэффициент масштаба и поворот без сдвига осей и растяжения. Рамка не обрезает рисунок; за пределами фотографии PNG, естественно, обрезается. Четыре угла можно двигать; крестик меняет позицию, масштаб и поворот регулируются справа. Физические размеры поверхности в этом режиме не участвуют в обработке.

**Перспектива плоскости.** Выберите режим, введите реальные ширину/высоту в одинаковых единицах и отметьте подтверждение. До подтверждения предпросмотр остаётся без деформации. Изменение размеров или переключение режима снимает подтверждение. В этом режиме пропорции логотипа сохраняются в координатах физической плоскости; на фотографии он получает соответствующее перспективное сокращение и обрезается по границам выбранной поверхности. Размеры не восстанавливаются по видимым длинам рёбер фотографии.

Автопоиск и загрузка новой фотографии всегда возвращают режим без деформации и снимают подтверждение. Они не меняют введённые физические размеры. Это исключает автоматическое включение перспективы на основании предположения. Для изогнутых изделий (кружек, бутылок и пр.) используется режим без деформации; оборачивания по цилиндру нет. «Показать область нанесения» скрывает вспомогательные элементы; в PNG они не входят.

## Проверки

`npm test`: OpenCV.js — перспектива, альфа, повторяемость четырёх режимов; маска/перекрашивание, сохранение оригинальных пикселей, внутренние области, автоподсказка и её отсутствие, прямое/обратное отображение точки при переносе логотипа. Дополнительно проверяются ортогональность и равенство масштаба осей обычного размещения, независимость от физических размеров, подтверждение перспективы, отсутствие обрезки по рамке в обычном режиме и правильные пропорции в координатах перспективной поверхности.

Браузерный сценарий на Chromium проверяет загрузку JPG отдельно от фотографии, удаление фона/перекрашивание/PNG, предложение поверхности при загрузке фото, drag логотипа, ZIP и перезагрузку с восстановлением настроек. Сравниваются PNG до и после выбора неподтверждённой перспективы (должны совпадать), после подтверждения (должны отличаться); проверяется сброс подтверждения автопоиском без изменения физических размеров. Ошибок консоли нет.

```sh
npm run dev -- --port 5174
# в другом терминале
npx playwright install chromium
npm run test:e2e
```

Для другой площадки задайте BRANDMOCK_TEST_URL. При нестандартном расположении Chromium задайте BROWSER_EXECUTABLE. Артефакты теста пишутся в игнорируемую test-artifacts/. Тестовый JPG создан для проекта, чужие логотипы не используются.
