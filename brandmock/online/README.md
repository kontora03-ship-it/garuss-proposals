# BrandMock Online 0.1

Онлайн-версия BrandMock: React/TypeScript/Konva + OpenCV.js 4.11, IndexedDB и JSZip. Нативная Python-версия остаётся рядом в репозитории Garuss.

## Возможности

- JPG/PNG/WebP фото, SVG и растровые логотипы, 4 угла плоскости.
- Перспектива OpenCV warpPerspective с premultiplied alpha, четыре программных эффекта, масштаб/поворот/позиция.
- PNG исходного разрешения, до/после, переносимый ZIP с оригиналами и JSON версии 1 (совместим с Python-прототипом).
- Последний проект восстанавливается после перезагрузки. Сохранение — кнопкой или перед экспортом.
- Фотографии и логотипы **не отправляются на сервер**. Исходные байты в ZIP не изменяются.

## Хранение и ограничения

Проекты хранятся только в IndexedDB этого браузера/профиля/домена. Очистка данных сайта удалит их. Для резервной копии и работы на другом устройстве скачивайте ZIP. Облачной синхронизации нет.

Файлы до 20 МБ, фото до 12 Мп, архив до 25 МБ. Большие изображения могут замедлять интерфейс. Только плоские поверхности; физическая симуляция и автоопределение поверхности отсутствуют. Тиснение — визуальная имитация. SVG поддерживает безопасное подмножество без CSS/scripts/image/use/внешних ресурсов и растрируется до 1600 px. Текст SVG зависит от системных шрифтов — переводите в кривые.

Цвет и декодирование изображений выполняет браузер; ICC/CMYK-цветопроба не поддерживается. Результат браузерного движка может не совпадать побайтно с Python-версией из-за декодирования, шрифтов и границ маски. Детерминизм проверяется внутри одного движка. Прозрачные пиксели исходного PNG с ненулевым скрытым RGB могут нормализоваться Canvas; оригинальный файл в ZIP сохраняется без изменений.

Первый запуск загружает локально размещённый OpenCV.js (~11 МБ); платных API нет. OpenCV — Apache 2.0, JSZip — MIT/GPL; см. THIRD_PARTY.md. Авторские тестовые сцены и источники фотографий перечислены в public/samples/SOURCES.md.

## Разработка

```sh
npm ci
npm test
npm run dev
npm run build
```

Статическая сборка в dist, параметры Sites в .openai/hosting.json. Рабочая публикация размещена на GitHub Pages в публичном репозитории Garuss. Sites не удалось опубликовать из-за ошибки провайдера.

## Проверки

17 проверок Node/OpenCV.js: перспектива, валидность углов, отверстия, исходные пиксели вне покрытия, прозрачность, нулевая непрозрачность, повторяемость во всех режимах. Компиляция TypeScript и production-сборка проходят. Браузерная проверка этой онлайн-версии не выполнена: в текущем managed-окружении отсутствует разрешённый инструмент cua_repl.js. Локальный Python-прототип имеет собственные 21 тест и ранее проверенные браузерные сценарии.
