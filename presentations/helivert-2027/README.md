# HELIVERT — квартальные календари 2027

Отдельная интерактивная презентация в стиле GARUSS. Четыре концепции, описания, сравнение, увеличение PNG и сохранение выбора в браузере.

## Просмотр

Откройте `index.html` в браузере. Все изображения и шрифты включены в папку `assets`; подключения к внешним сервисам нет.

Для локального HTTP-просмотра запустите из этой папки:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Структура

- `index.html` — страница презентации.
- `style.css` — оформление, адаптивность и анимация.
- `app.js` — переключение концепций, сравнение и просмотр макетов.
- `assets/calendar-1.png` … `calendar-4.png` — исходные PNG с прозрачностью.
- `assets/*.ttf` — предоставленные фирменные шрифты.
- `assets/garuss.svg` — логотип GARUSS.

Презентация сохранена отдельно от сайта. Публикация, GitHub Pages, подключение к каталогу и изменение действующей главной страницы не выполнялись. Конфигурация Sites в эту папку не включена.
